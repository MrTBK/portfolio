## 🎨 Website Architecture & Features

This portfolio is built with modern frontend engineering principles designed for maximum speed, accessibility, and visual elegance:

- **Executive Dark Aesthetic**: Dark slate background with cyan ambient glows, glassmorphism panels, and clean typographic hierarchy.
- **Zero-Dependency Core**: Pure HTML5, Tailwind CSS, and lightweight Vanilla JavaScript for lightning-fast loads.
- **Interactive Project Filtering**: Instant categorization across *Data & BI*, *Web & Applications*, and *Applied AI & Analytics*.
- **Scrollspy Navigation**: Real-time active section indicator tracking user scroll position.
- **High-Resolution Lightbox**: Tap- or click-to-zoom modal for inspecting project previews and contest photographs in full resolution.
- **Mobile-First Responsiveness**: Tailored layouts for seamless browsing across smartphones, tablets, and ultra-wide desktop monitors.
- **Quick-Action Utilities**: One-click clipboard copy with animated toast notifications for contact info, and direct PDF CV download.
- **Open Graph Ready**: Rich metadata tags providing clean link preview cards when shared on LinkedIn, WhatsApp, X/Twitter, and Discord.

## 🛠️ Running Locally

Anyone can clone and run this portfolio locally without requiring Node.js or external package managers:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MrTBK/portfolio.git
   cd portfolio
   ```

2. **Serve with any local web server:**
   ```bash
   # Using Python 3:
   python3 -m http.server 8000
   ```

3. **View in your browser:**
   ```text
   http://localhost:8000
   ```
