## 🚀 Features

- **Clean & Modern UI**: Subtle ambient glows, glassmorphism panels, and smooth micro-interactions.
- **Sleek Dark Theme**: High-contrast, executive dark aesthetic with glowing cyan accents.
- **Interactive Project Filtering**: Filter projects by categories (`All`, `Data & BI`, `Web & Applications`, `Applied AI & Analytics`).
- **Scrollspy Navigation**: Automatic active section tracking with glowing navigation indicators.
- **High-Resolution Lightbox**: Click any project preview or competition photograph to zoom into full resolution with captions.
- **Direct GitHub Repository Access**: Links straight to project source code across featured repositories.
- **One-Click Clipboard Copying**: Effortlessly copy email and phone number with feedback toast notifications.
- **Resume Download**: One-click download of the latest CV in PDF format.
- **Open Graph Social Previews**: Rich social sharing cards for LinkedIn, WhatsApp, Discord, and Twitter/X.
- **Zero Build Step**: Pure HTML5, modern Tailwind CSS, and Vanilla JavaScript. Works out-of-the-box in any browser.

## 💻 How to Run Locally

You can open `index.html` directly in any web browser:

```bash
# Using Python's built-in HTTP server:
python3 -m http.server 8000

# Open in your browser:
# http://localhost:8000
```

## 🌐 Deploy to GitHub Pages (Free)

1. Initialize git and push to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/MrTBK/portfolio.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Source**, select **Deploy from a branch** > branch `main` / folder `/ (root)`.
   - Click **Save**. Your portfolio will be live at `https://mrtbk.github.io/portfolio/` in seconds!
